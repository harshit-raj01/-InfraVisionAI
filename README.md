# InfraVision AI

## Infrared Image Colorization and Enhancement for Improved Object Interpretation

InfraVision AI is a computer vision project that enhances infrared/thermal images, applies colorization, detects objects using YOLOv8, and generates scene interpretation.

## Features

* Infrared image enhancement using CLAHE
* Thermal image colorization
* Object detection using YOLOv8
* AI-based scene interpretation
* Streamlit web interface

## Technologies Used

* Python
* OpenCV
* Streamlit
* YOLOv8
* NumPy
* PyTorch

## How to Run

1. Create virtual environment

python -m venv venv

2. Activate environment

venv\Scripts\activate

3. Install dependencies

pip install -r requirements.txt

4. Run application

streamlit run app.py
