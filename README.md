# InfraVision AI

InfraVision AI is an AI-powered web application for enhancing and interpreting infrared images. The application provides image enhancement, colorization, and visualization through an interactive Streamlit interface.

## 🚀 Live Demo

https://mkcfpga4e97zkiuytwol2c.streamlit.app/

## Features

* Infrared image enhancement using OpenCV
* Image colorization
* Interactive Streamlit web interface
* Easy image upload and processing
* Real-time results visualization

## Technologies Used

* Python
* Streamlit
* OpenCV
* NumPy
* Pillow

## Project Structure

```text
app.py
enhancement.py
colorization.py
detection.py
requirements.txt
packages.txt
runtime.txt
README.md
```

## Installation

```bash
pip install -r requirements.txt
```

## Run Locally

```bash
streamlit run app.py
```

## Usage

1. Open the application.
2. Upload an infrared image.
3. View the enhanced image.
4. View the colorized image.
5. Download or analyze the results.
